# Фотки для hero

Сюда положи 4 картинки с такими именами:

- `1.jpg` — верхний левый стикер
- `2.jpg` — верхний правый
- `3.jpg` — нижний левый
- `4.jpg` — нижний правый

## Что выбирать

- Соотношение сторон **4:5** (вертикальные). Можно квадрат или 3:4 — обрежется по object-fit: cover, не страшно.
- Размер по большей стороне ~800px достаточно. Слишком тяжёлые картинки замедлят сайт. Если jpg больше 300кб, прогони через [squoosh.app](https://squoosh.app/) или [tinypng.com](https://tinypng.com/).
- Любой цвет — на сайте они автоматически становятся ч/б. При наведении возвращают цвет.

## Где взять

Pinterest, Unsplash, свои фотки. Сохраняй как `1.jpg`, `2.jpg`, `3.jpg`, `4.jpg`.

## Если хочешь больше фоток

В `index.html` найди блок `.stickers` и добавь ещё `<figure class="sticker"...>`, у каждой задай свои `--rot`, `--x`, `--y` (проценты по экрану) и подключи новый `5.jpg`.

## Если хочешь убрать ч/б фильтр

В `style.css` найди `.sticker img` и убери строку `filter: grayscale(1) contrast(1.05);`.
